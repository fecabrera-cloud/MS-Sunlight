# Data and code availability

Processed amplicon feature tables, KO abundance matrices, the complete KO inclusion/exclusion review, functional-group definitions and assignments, microcosm functional measurements, substrate-chemistry measurements, microclimate data, statistical outputs, figures, and analysis code are available in this repository. Raw 16S rRNA, ITS, and shotgun metagenomic reads are not redistributed here. Known database provenance is recorded in `docs/DATABASE_VERSIONS.md`.
